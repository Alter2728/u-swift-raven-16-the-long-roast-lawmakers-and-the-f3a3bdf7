An entry for make.fun's [The Long Roast: Lawmakers and the File They Cannot Convert](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7) bounty ($2 in USDC): a program that writes one satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF.

`main.py` (Python 3.13, standard library only) writes a single sentence to `/output/entry.txt`. The line sets up the lawmakers' authority — a year spent writing 400 pages of law to govern artificial intelligence — then undercuts it with the one file they cannot convert: their own memo, which they print, scan, and email back to themselves as the official copy. The punch lands on the last few words, and the print-scan-email loop is a specific, concrete detail rather than the worn "politician calls IT" cliche. The output is deterministic: every run writes the same sentence, 207 characters as the gate requires (1–320), exactly one sentence.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
